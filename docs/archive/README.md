# Qx 文档历史归档

> 状态：Historical · 非权威资料

这里保存已经被当前代码或规范取代、但仍有追溯价值的设计、任务台账、用户指南和内部工作记录。

## 使用边界

- 归档内容解释“当时为什么这样做”，不定义当前接口、目录、快捷键或产品能力。
- 文中未完成的 PR、开放问题和复选框不会自动成为当前任务；当前工作只看根目录 [`TASK.md`](../../TASK.md)。
- 实现时从 [`docs/README.md`](../README.md) 进入当前架构，从 [`public/doc/README.md`](../../public/doc/README.md) 进入公开协议。
- 归档文件不参加维护中文档的链接门禁；旧链接、旧版本号和旧路径可以作为历史证据保留。
