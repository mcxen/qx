# 社区插件主搜索验收

日期：2026-09-06。范围：宿主插件搜索端口、21 个社区插件的声明式搜索词。

## 协议

插件的 Manifest 保存中文常用词、无声调拼音全拼和首字母。宿主从已注册的面板/命令
投影搜索结果，不执行插件、不读取远程数据。普通注册和延迟注册共享
`buildPluginSearchTerms`。结果携带关键词匹配分数进入统一排序；未注册、停用的外部插件
不能凭安装元数据产生可执行入口。只有命令的插件返回真实命令路径。

Launcher 默认选择与全局排序共享相关性比较规则。同等级下，条目自身名称命中优先于
仅继承插件名或关键词的命令；例如 `v2` 默认选择 V2EX 面板，`token` 仍选择令牌命令。
置顶项可以继续显示，但不匹配时不会自动选中。新查询或范围重置自动选择；用户手动
选择后，增量结果按稳定行 key 保留选择。折叠分组中的条目不参与默认选择。

## 消融

误匹配回归：V2EX 的通知和令牌命令说明包含 `requires token`，旧索引使 `qui` 命中二者。
索引排除说明字段后，`qui` 不返回 V2EX，仍返回 Quick Calendar；`token` 仍命中显式命令词。
显示层保留命令标题，避免不同命令都被插件名称覆盖。

独立消融：保留旧说明词索引时重现两条误匹配；只修显示仍有两条结果，但动作标题可区分；
只修索引排除两条误匹配；组合修复同时保障相关性与动作名称，且保留全部中文别名验收。

本机补验：全量 `npm run check` 和 macOS app 构建通过，Apple Development 签名后替换
`/Applications/Qx.app` 并校验二进制一致。用户新截图中 `qui` 的外置插件仅有快捷日历，
V2EX 两条误匹配消失。命令名称的中英文区分由生产显示函数回归测试覆盖。

使用同一个日历插件样本，在英文界面中隔离声明词和宿主索引。基线采用修复前的
canonical name/id/keywords 匹配字段和原有两字符保护，不把新增关键词混入基线。

| 配置 | 日历 | rili | rl | 英文界面搜完整中文名 |
| --- | --- | --- | --- | --- |
| 基线 | 不命中 | 不命中 | 不命中 | 不命中 |
| 只补插件声明词 | 命中 | 命中 | 命中 | 命中 |
| 只修宿主索引 | 不命中 | 不命中 | 不命中 | 命中 |
| 两者组合 | 命中 | 命中 | 命中 | 命中 |

排序单独消融：仅补词时，发布出的结果丢失关键词分数，`rili` 对可见名称 `快捷日历`
得到 none，落后于应用 `rili helper`；带 `matchScore` 后精确别名优先于该前缀匹配。

刷新单独消融：插件数量不变但关键词变化时，metadata fingerprint 必须变化；仅替换
runtime render 回调时保持不变。活动查询刷新保留 version guard，普通键入只进入原有
防抖流程，不再由 metadata effect 重复启动搜索。

## 自动验证

`npm run test:plugin-search`：

- 21 个源插件，每个声明中文/拼音/缩写验收词；中英文界面共 542 次目录检索断言。
- 中文命令标题在英文界面同样命中；无面板插件只返回真实命令。
- 停用、未注册、移除后残留注册、内置模块搜索开关均有定向检查。
- 用户 aliases/tags 保留；`ip` 不误匹配 `clipboard`。
- 精确别名分数保留到全局排序；同数量词表更新能改变 fingerprint。
- 索引和匹配不调用 render/run；测试词表不进入宿主运行时代码。

源码词表位于各 `qx-plugins/src/<id>/manifest.json`；验收词表位于
`scripts/fixtures/plugin-search-cases.json`。新增插件需加入验收范围。
