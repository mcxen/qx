# v0.6.120 — 修复 Windows 无法截图

修复圈选时报 `show region picker: the underlying handle is not available` 后，后续截图仍不断复用失效窗口的问题。截图和录屏现在检查真实原生窗口，失效时自动重建，正常窗口继续复用。

恢复后的圈选、外屏遮罩、Esc/原生关闭、倒计时穿透和录屏边框使用同一窗口身份。补齐恢复窗口与外屏遮罩的事件/窗口权限。创建或显示失败时清理已出现的遮罩与会话，再恢复原界面，避免留下阻挡桌面输入的捕获层。

已通过完整仓库门禁、TypeScript、Vite 生产构建、Windows MSVC Rust 编译和格式检查，以及最终 Tauri release 构建与 MSI/NSIS 打包。真实 WebView2 回归覆盖失效 HWND 注入、自动重建、逻辑窗口解析、连续复用和 3 个窗口的 27 项浏览器策略检查。隔离窗口测试不等同已安装客户端的截图成品、多屏、录屏或 macOS 实机验收；本机安装版未替换。
