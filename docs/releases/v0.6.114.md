# Qx v0.6.114

- QxShell 统一按钮、Context、菜单和快捷键的 Action 执行，支持异步防连击、失败重试与子菜单过期结果保护；搜索菜单保留原生编辑和 IME，关闭恢复焦点。
- 错误始终进入固定高度灵动岛。窄窗压缩摘要但保留可点击详情、恢复与关闭入口；设置预览不覆盖真实任务和错误，录制红色与错误语义分离。
- Context 和主从分栏共享拖动、键盘、边界与存储控制器；按帧更新、结束持久化，宽度不跨 Shell 泄漏。模块声明 scroll/fill 布局并复用 shellProps。
- 新增生产逻辑与浏览器消融回归，覆盖异步拒绝/竞态、Esc、焦点、分栏和 120 组明暗主题、中英文、360–1200px 布局组合。

本版本仅包含 Shell/UI 批次，不包含同工作区并行开发的 QxAI 分类记忆改动。
验证范围及桌面实机待验项见 `docs/shell-refactor-validation.md`。
macOS ARM64 与 Windows x64 安装包由同一标签的 Release workflow 构建；触发工作流不代表安装包已发布。
GitHub macOS 产物使用 ad-hoc 签名且未公证。
