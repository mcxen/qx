# Qx v0.6.112

- QxAI 的思考过程与工具调用默认压缩为单行活动摘要，连续工具可分组查看，完整参数、结果与时间线仍可按需展开。
- 重新生成会保留同一条助手消息的候选版本，失败或异常中断会恢复原回复；代码块与附件操作也改为更紧凑的桌面交互。
- AI Agent 设置重组为「Agent 与模型」「工具与安全」「Skills 与 MCP」「自动化」四个分区，并按分区延迟加载资源。
- 修复宏录制轨迹、停止与暂停取消时序，改善高频鼠标移动和输入法场景下的录制、回放稳定性。
