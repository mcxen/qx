# Qx v0.6.115 — Scoped memory and reliable extraction

- Separate explicit project scope from user / feedback / project / reference categories. Existing memories stay global; changing a conversation scope affects future turns only.
- Serialize automatic, manual and tool extraction; freeze the originating provider/model and content, split long turns without truncation, retry from the failed batch, and atomically record completed batches to prevent duplicate replay.
- Inject a bounded memory index and retrieve full records on demand. Scope and archive filters apply before search limits, including Chinese fallback search.
- Add scope filtering, search, source conversation links and retained-original inspection to Memory Management. Compression preserves sources, validates lineage and commits records/FTS together.
- Show extraction failures through the existing Island with retry; no extra error row beneath chat content or forms.

Validation: TypeScript, frontend production build, repository checks, Rust memory regression tests and synthetic browser UI checks. No live provider extraction-quality or installed macOS/Windows acceptance claim. Pending extraction jobs are process-local; completed-batch receipts persist. Desktop bundles are produced by the tag workflow; macOS artifacts use ad-hoc signing, not Developer ID notarization.
