# Qx v0.6.116 — Live reasoning clock and native file tools

- Replace vague QxAI reasoning duration text with a real run clock. It starts at the first reasoning or tool event, updates on aligned second boundaries, freezes on completion, and uses an accessible split-flap animation with reduced-motion support.
- Give reasoning, grouped tools and individual tool calls consistent compact disclosure surfaces. Expansion preserves nested choices and scrolling, while single calls now show returned values and explicitly identify an empty result.
- Add bounded native file inspection and editing tools: metadata, directory listing, globbing, line-based reads, whole-file writes and exact edits. Existing-file mutations require the SHA-256 revision returned by the prior read and still pass through dangerous-tool confirmation.
- Refine AI provider settings into a compact responsive list with focused add/edit dialogs, clearer model hierarchy and stable keyboard focus restoration.
- Split oversized QxAI tool and provider modules into focused adapters while preserving the existing Agent transport and settings contracts.

Validation: repository checks, TypeScript, production frontend build, QxAI Agent checks, synthetic browser interaction, Rust file-service regression tests, Rust formatting, native compile and a local Apple Silicon `.app` release build. The tag workflow builds the Apple Silicon macOS app/DMG and Windows x64 NSIS installer. Release macOS artifacts remain ad-hoc signed and are not Developer ID notarized; live-provider and installed-app acceptance are not claimed.
