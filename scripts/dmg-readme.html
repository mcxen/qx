Qx 安装说明

版本 __RELEASE_TAG__ · macOS Apple Silicon

推荐方式：拖动安装

  1. 将左侧的 Qx.app 拖到 Applications 文件夹快捷方式。
  2. 打开“应用程序”中的 Qx。首次打开若出现安全提示，请右键 Qx.app，选择“打开”。

备用方式：运行 install.sh

如果 macOS 阻止启动，打开终端，将本文件所在的安装盘窗口拖入终端以定位目录，然后运行：

bash install.sh

install.sh 会把应用复制到“应用程序”（没有写入权限时使用 ~/Applications），并移除下载隔离标记。

也可以手动执行一次：

xattr -dr com.apple.quarantine /Applications/Qx.app

Qx 当前使用免费签名，未进行 Apple 公证。首次启动出现提示属于 macOS 的安全检查；确认来源可信后，按上面的步骤操作即可。

支持 Qx

Qx 由个人持续维护。若它对你有帮助，欢迎按能力赞助，用于服务器、签名和持续开发；不赞助也完全不影响使用。
